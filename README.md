## 🔧 What I Build

**[CayPPer](https://github.com/Supersonic12/CayPPer)** — A Qt6/C++ wallpaper manager for Linux with automatic desktop environment detection. Supports KDE Plasma, GNOME, XFCE, Sway, Hyprland, and generic X11. Full Vim-style keyboard navigation, multi-monitor awareness, and system theme integration. ~100 commits of iterative systems-level work.

**[Bash Scripts](https://github.com/Supersonic12/bashscriptsofmine)** — A collection of shell tools I actually use daily. Real-world automation, not tutorial exercises.

**[Linux Beginner Minilab](https://github.com/Supersonic12/linux-beginner-minilab)** — Hands-on lab for learning Linux commands. Built to teach, not just document.

**[Dotfiles](https://github.com/Supersonic12/.dotfiles)** — My dwm-flexipatch, dwmblocks, picom, dunst, and rofi configuration. Minimal, fast, intentional.
